# Szczotok Finanse – strona WWW

Statyczna strona gotowa do publikacji na GitHub Pages.

## Pliki
- `index.html` – treść strony
- `styles.css` – wygląd
- `script.js` – menu mobilne i rok w stopce
- `logo.png` – logo

## Publikacja na GitHub Pages
1. Utwórz nowe repozytorium, np. `szczotokfinanse`.
2. Wgraj wszystkie pliki z tego folderu do głównego katalogu repozytorium.
3. GitHub → Settings → Pages.
4. Source: `Deploy from a branch`.
5. Branch: `main`, folder: `/ (root)`.
6. Po zakupie domeny `szczotokfinanse.pl` dodaj ją jako Custom domain.

## Do podmiany przed publikacją
W `index.html` zamień:
- `+48 000 000 000` na właściwy numer telefonu,
- `kontakt@szczotokfinanse.pl` na właściwy adres, jeśli będzie inny.

Formularz korzysta obecnie z `mailto:`. Jeśli chcesz prawdziwy formularz bez otwierania programu pocztowego, można później podpiąć np. Formspree lub backend.
